Abrir Orca Web com este acesso

No Orca Desktop, abra Settings → Remote Orca Servers → Add Server e cole a URL. O QR code contém o mesmo link.

Este link concede acesso ao servidor. Compartilhe apenas com o dispositivo que deseja parear.

O Orca Web e a conexão do desktop usam o endpoint público. O token deste link autentica o acesso; a geração de links fica restrita ao proprietário no Coder.
